# Common Wix Debugging Issues

## Dataset Not Loading
Possible Causes:
- permissions
- dataset not connected
- preview vs published mismatch

## Hooks Not Firing
Possible Causes:
- backend file placement
- export naming issue
- collection permissions

## Backend Import Failures
Possible Causes:
- incorrect module path
- frontend importing backend directly

## OAuth Token Failures
Possible Causes:
- invalid scopes
- redirect mismatch
- expired refresh token

## Webhook Failures
Possible Causes:
- invalid endpoint
- missing HTTPS
- signature verification issues
